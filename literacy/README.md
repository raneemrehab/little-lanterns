# Learning Lanterns · 28 game designs (visual phase)

Visual designs for every game in the production tracker, awaiting review. Nothing here is a playable game.

| File | What it is |
| --- | --- |
| `index.html` | The review gallery: all 28 designs (start, play, right answer, try again, complete and phone screens), the tracker, the voiceover list, the research map and open decisions. Open it in a browser. |
| `tracker.md` | Master tracker for the 28 games. |
| `voiceover-master-list.csv` / `.md` | Every line to record, with IDs like `LL-LIT-G01-VO01-introduction`, triggers, notes and filenames. |
| `research-mapping.md` | Per-game design notes and the research-to-design map. The source cites no research, so it holds design rationale only. |
| `src/games.js` | The single source for all of the above. Edit here, then run `node literacy/build.mjs`. |

Games 1–12 are the Literacy curriculum; 13–27 are the Main curriculum; 28 is a proposed game. Names and numbers follow the production tracker.
